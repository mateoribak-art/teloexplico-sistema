Conectá la oficina con GitHub

La oficina lee el estado del repo privado teloexplico-sistema. La clave queda guardada solo en este navegador y solo se manda a GitHub.

  1. Abrí github.com → Fine-grained token nuevo.
  2. Nombre: oficina · Vencimiento: 1 año · Repository access: Only select repositories → teloexplico-sistema.
  3. Permissions → Repository: Contents: Read and write y Actions: Read and write (para leer el estado, dejar pedidos, pausar y relanzar).
